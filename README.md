\# Рекурсия и стек



Учебный проект по алгоритмам и структурам данных.



\## Что реализовано



1\. \*\*К1\*\* — рекурсивный факториал `factorial(n)`.

2\. \*\*К2\*\* — рекурсивная сумма списка `recursive\_sum(arr)` с базовым случаем.

3\. \*\*К3\*\* — рекурсивный бинарный поиск `binary\_search\_recursive(arr, target)`.

4\. \*\*К4\*\* — класс `Stack` с методами `push`, `pop`, `peek`, `is\_empty`.



\## Анализ



\### Факториал

\- \*\*Временная сложность:\*\* O(n).

\- \*\*Базовый случай:\*\* `n <= 1` возвращает 1.

\- \*\*Пространственная:\*\* O(n) — глубина рекурсии.



\### Сумма списка

\- \*\*Временная сложность:\*\* O(n).

\- \*\*Базовый случай:\*\* пустой список возвращает 0.



\### Рекурсивный бинарный поиск

\- \*\*Временная сложность:\*\* O(log n).

\- \*\*Базовый случай:\*\* `left > right` → элемент не найден (-1).



\### Стек

\- `push(item)` — добавить элемент.

\- `pop()` — удалить и вернуть верхний.

\- `peek()` — посмотреть верхний без удаления.

\- `is\_empty()` — проверить пустоту.

\- Все операции — O(1).
